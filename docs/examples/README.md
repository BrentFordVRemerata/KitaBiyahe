# Fictional examples

Fictional Shift Examples.json contains two demonstration records, not a rider's history. Use Settings > Import backup file > Merge shifts to add them while preserving your existing records and motorcycle settings. Reimporting the same file does not duplicate its stable IDs. Replace all replaces your entire current history and settings; export a backup first.

The complete example is PHP1,200 earnings minus PHP162.50 estimated fuel and PHP80 other cost = PHP957.50 before reserve, then minus PHP100 planned maintenance reserve = PHP857.50. The PHP500 example keeps unknown costs as null and remains incomplete. These figures do not establish actual profit or money in a wallet.
